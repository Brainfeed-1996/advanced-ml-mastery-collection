# Advanced ML Mastery Collection

Comprehensive collection of 30+ Machine Learning and Deep Learning projects.

## Structure

```
advanced-ml-mastery-collection/
├── 01-Regression/          # Linear/Polynomial regression
├── 01-Regression-Analysis/ # Statistical analysis
├── 02-Classification/     # Classification algorithms
├── 02-Classification-Challenges/ # Competition-style
├── 03-Clustering/          # K-means, DBSCAN, Hierarchical
├── 03-Clustering-Techniques/ # Advanced clustering
├── 04-NLP/                 # Natural Language Processing
├── 04-Natural-Language-Processing/
├── 05-Computer-Vision/    # CNN, Image processing
├── 06-Reinforcement-Learning/ # Q-learning, DQN
├── 07-Time-Series/         # Time series analysis
├── 07-Time-Series-Forecasting/
├── 08-Anomaly-Detection/   # Isolation Forest, LOF
├── 09-Generative-AI/       # GANs, VAEs
├── 10-MLOps/               # ML pipelines
├── 10-MLOps-Production/
├── 11-Advanced-Signal-Processing/
├── core/                   # Shared utilities
├── docs/                   # Documentation
└── tools/                  # Maintenance scripts
```

| Topic | Notebooks |
|-------|-----------|

| Anomaly Detection | Isolation Forest, LOF, Autoencoders |
| Generative AI | GANs, Variational Autoencoders |
| MLOps | Pipelines, Model serving |
